# Alepejo Plataforma SaaS

## Objetivo

Construir um ERP SaaS comercial de nível Enterprise.

Nunca gerar código temporário.

Nunca criar soluções paliativas.

Todo código deve ser preparado para produção.

---

## Arquitetura

Backend

- NestJS

- Prisma

- PostgreSQL

Frontend

- Next.js

- TypeScript

- Tailwind

---

## Regras

Sempre preservar arquitetura existente.

Nunca remover funcionalidades já implementadas.

Sempre reutilizar componentes.

Sempre utilizar SOLID.

Sempre utilizar Clean Code.

Sempre utilizar Repository Pattern.

Sempre utilizar DTO.

Sempre utilizar Services.

Sempre utilizar Dependency Injection.

Nunca duplicar código.

Nunca gerar código morto.

Nunca criar arquivos desnecessários.

---

## Desenvolvimento

Antes de alterar qualquer arquivo:

1. analisar dependências

2. analisar arquitetura

3. verificar impacto

4. somente depois implementar

---

## Entregas

Sempre entregar código compilável.

Nunca deixar erros acumulados.

Uma funcionalidade por Sprint.
